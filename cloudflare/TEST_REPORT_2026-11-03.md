# BHH Drug Formulary 2.0 — Preproduction Foundation Test Report
Date: 2026-11-03 (Asia/Bangkok)

## Decision
**Cloudflare + the original Google Apps Script DriveApp model** retained.
No R2. No Google service account. Existing production GitHub Pages, Apps
Script Web App, Google Sheet, Google Drive permissions and Google Docs PDF
template remain unchanged.

**Preproduction UAT is NOT approved** until staging Apps Script deployment,
Cloudflare Access and end-to-end browser tests complete.

## Source-based Drive behavior
- `backend/apps-script/DriveService.gs` uses the existing Apps Script account's
  `DriveApp`, Script Properties main folder, per-year submission root and
  `SUBMISSION_FOLDER_DEFINITIONS` (14 categories).
- File names are generated by the existing `buildStoredFileName_()`.
- The existing `GeneratePdfService.gs` copies the approved Google Docs
  template and writes PDFs to `11_Generated_Physician_Form`.
- New `CloudflareDriveBridge.gs` in a **staging copy** of Apps Script reuses
  those helpers, with an HMAC signed request, nonce/time validation and
  staging-root confinement. No new OAuth credentials required.
- D1 schema migration `0004_original_drive_folder_map.sql` stores the
  original folder tree references for new D1 records.
